# Study Case Brief

## Business context

Australian charities operate across very different sizes, funding models, workforce structures and reporting environments. The study case asks how public ACNC information can be transformed into a reliable analytical product that helps stakeholders understand sector structure, financial sustainability and operating capacity.

## Core analytical questions

1. What does the Australian charity landscape look like by organisation size and registration status?
2. How concentrated are charity revenues and assets across the sector?
3. How dependent are charities on government funding and donations?
4. How do workforce and volunteer models differ by charity size?
5. What financial sustainability patterns emerge across charity segments?
6. Which areas represent potential service, capability or community-impact opportunities?

## Analytical principle

Start from the source table, establish data quality, build a governed relational model, then answer business questions from curated analytical views.

## Deliverables

- SQL ingestion pipeline
- Data dictionary
- Data-quality and reconciliation report
- Relational data model
- Python analysis notebooks
- Power BI prototype / final dashboard
- Business insight narrative

## Success criteria

The database must reconcile to the source at the defined grain, critical measure aggregates must align, NULL handling must be understood, and all material data-quality exceptions must be documented.
