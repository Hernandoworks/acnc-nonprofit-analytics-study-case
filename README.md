# Non-Profit Study Case 01

End-to-end analytics case study using Australian non-profit / charity data.

## Study Case Structure

1. **Data Preparation & Modelling** — understand, prepare, validate and model the data.
2. **Complex SQL & Analytics** — solve analytical problems using SQL.
3. **Data Engineering** — productionise the logic with dependencies, quality controls and CI/CD.
4. **Power BI** — turn trusted analytical data into a business-facing trend and opportunity solution.

## Business Question
> **Where is Australia's non-profit sector changing, and what opportunities are emerging from those changes?**

## Portfolio Story
**Analyst first → Analytics → Engineering → Business Intelligence**
