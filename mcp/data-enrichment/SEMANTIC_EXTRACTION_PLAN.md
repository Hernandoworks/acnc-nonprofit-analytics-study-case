# Semantic extraction plan

Semantic enrichment will remain conservative and evidence-backed.

Phase 1: identify explicit page sections for programs, services, what we do, our work and about.
Phase 2: preserve source text and source URL rather than inventing summaries.
Phase 3: optionally normalize extracted sections into profile-specific fields.
Phase 4: require verification/review for semantic attributes before treating them as authoritative.

No private contact inference. No unsupported claims. Commercial LLM or enrichment services remain optional adapters.
