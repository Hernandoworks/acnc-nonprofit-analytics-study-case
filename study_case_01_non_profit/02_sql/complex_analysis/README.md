# Complex SQL Analysis

This folder contains the advanced SQL questions for Study Case 01.

## Analysis themes

1. Charity population and size distribution
2. Revenue concentration
3. Government funding dependency
4. Donation dependency
5. Financial sustainability and net margin
6. Asset / liability structure
7. Workforce capacity and FTE intensity
8. Volunteer intensity
9. Key Management Personnel remuneration
10. Size-segment benchmarking
11. Financial outlier detection
12. Multi-dimensional charity segmentation

## SQL standard

Queries should demonstrate CTEs, window functions, conditional aggregation, percentile functions, ranking, cohort/segment comparisons, NULL-safe calculations and business-rule validation where appropriate.

## Output standard

Each analysis should contain:

- business question
- SQL query
- result interpretation
- analytical caveat
- Power BI implication
