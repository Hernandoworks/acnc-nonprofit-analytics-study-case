# Data Profiling Plan

## Objective
Understand data structure and quality before transformation or modelling.

## Profiling checks

- Row count
- Column count
- Data type
- NULL / blank count
- Distinct count
- Duplicate candidate keys
- Minimum / maximum dates
- Numeric ranges
- Category distributions
- Referential integrity candidates
- Unexpected values

## Output

Profiling results feed the data-preparation and modelling decisions. No business metric should be treated as production-ready until its grain and quality are understood.
